Valor da Joia — 5 ideias

Todas já com os dois ajustes: peso exato (digitado com teclado numérico próprio na tela, com vírgula e “g”) e mais de uma joia na mesma avaliação, com um valor final só. As ideias mudam a forma de navegar; cores, fontes e componentes continuam os mesmos.
A tela de resultado (no fim) serve para todas.

A
Lista de cartões

Tudo numa tela só, rolando. Cada joia é um cartão. A joia que você terminou fecha num resumo de uma linha; a atual fica aberta. Embaixo, “Adicionar outra joia”.

A favorMais próxima do mockup anterior. Vê tudo de uma vez, edita qualquer joia com um toque.
ContraCom 3+ joias a tela fica longa. O teclado numérico divide espaço com o formulário.

Passo a passo

Uma pergunta por tela, bem grande. Depois da última pergunta de cada joia, uma tela pergunta: “Adicionar outra joia” ou “Ver valor”.

A favorA mais fácil para quem nunca usou. Zero chance de se perder. O teclado do peso cabe gigante.
ContraMais toques no total. Para revisar uma resposta antiga é preciso voltar.

C
Formulário + bandeja (iPad deitado)

iPad na horizontal. À esquerda, o formulário da joia atual. À direita, uma “bandeja” com as joias já incluídas, como um carrinho. O botão de avaliar fica na bandeja.

A favorBom para atendente e cliente lado a lado no balcão. A lista de joias está sempre visível.
ContraObriga o iPad deitado. Mais elementos na tela ao mesmo tempo.

D
Abas por joia

Cada joia é uma aba no topo (“Joia 1”, “Joia 2”, “+”). O formulário embaixo é sempre o mesmo, com o teclado do peso já fixo na tela, sem precisar abrir.

A favorA tela nunca muda de tamanho nem rola. Pular entre joias é um toque.
ContraAs abas escondem o que já foi preenchido. Para ver tudo junto, só no resultado.

E
Frase para completar

Em vez de formulário, uma frase com lacunas: “Tenho um anel de ouro 18k com 12,40 g”. Tocar numa lacuna abre as opções embaixo. Cada joia nova acrescenta uma linha que começa com “e um…”.

A favorA mais diferente e com mais cara de joalheria. Lê como conversa, explica sozinha.
ContraFica estranha se as características crescerem para 5 ou mais. Menos convencional, o atendente pode estranhar no começo.
